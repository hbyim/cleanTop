# 덜기

이번 주에 줄일 알림, 구독, 약속을 한곳에 모아 두는 주간 정리 웹앱입니다.

카카오톡 알림을 대신 끄거나, 넷플릭스와 쿠팡 와우를 대신 해지하지는 않습니다. 휴대폰과 각 서비스가 그 권한을 외부 앱에 주지 않기 때문입니다. 덜기는 확인 시간을 정해 두고, 구독 금액과 해지 페이지를 모아 두고, 실제로 연락할 사람의 다음 만남을 적고, 이번 주에 끊을 일 하나의 순서를 안내합니다.

기록은 이 브라우저의 로컬 저장소에만 남습니다. 계정은 만들지 않습니다.

## 실행

```bash
npm install
npm run dev
```

개발 서버는 [http://127.0.0.1:47231](http://127.0.0.1:47231) 에서 열립니다.

공개 주소는 [https://hbyim.github.io/cleanTop/](https://hbyim.github.io/cleanTop/) 입니다. `main`에 올리면 GitHub Actions가 정적 파일을 만들어 Pages에 배포합니다.

```bash
npm test
npm run lint
```

## 화면

- **이번 주.** 다음 확인 시간, 이번 주 끊을 것, 살펴볼 구독, 만날 사람을 한 화면에서 봅니다.
- **구독.** 이름, 금액, 결제일, 상태를 적습니다. 카드 내역을 붙여 넣으면 구독처럼 보이는 줄만 골라 줍니다.
- **사람.** 관계와 만남 간격을 적고, 만났거나 일주일 미룰 수 있습니다.
- **확인 시간.** 하루 두세 번의 메신저 확인 시간을 정합니다. 브라우저 알림은 이 탭이 열려 있을 때만 울립니다.

처음 화면의 **예시로 둘러보기**로 샘플 한 주를 볼 수 있습니다.

## 나중에 모바일 앱으로 넓힐 때

화면과 저장 규칙은 웹에서 먼저 확인합니다. `src/lib`의 시간 계산, 구독 분류, 영수증 판별은 화면과 분리되어 있어서 이후 앱에서도 같은 규칙을 쓸 수 있습니다.

모바일에서 더할 수 있는 것은 앱이 닫혀 있을 때의 알림입니다. 카카오톡 단톡 알림을 대신 끄거나, 카드사의 자동결제를 동의 없이 읽어 오거나, 다른 앱에서 로그아웃시키는 일은 웹과 마찬가지로 범위 밖에 둡니다.
